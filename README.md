# Hardik Anuvadiya

**Full-stack software engineer · Ahmedabad, India**

I build production software with the team at GTCSYS, and I like staying with a product after it ships. The interesting part is the real workflow: clear APIs, a UI people can finish a task in, and a system that is still healthy once it is in customers' hands.

Since October 2022 that work has covered AI platforms, real estate, utility billing, compliance, digital identity, automotive, and manufacturing. Most of it lives in private repositories. This profile is the public side: how I work, the stack I use, and the code I can share.
